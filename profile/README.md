# Vibe Memory

**One memory. All your agents. Your infrastructure.**

A self-hosted memory graph and keyword index for Claude Code, Codex, OpenClaw, Hermes, and any agent that can use REST.

The agent performs reasoning, entity/relationship inference, file analysis, and keyword extraction. The service manages data and embeds only the supplied keywords locally — no server-side LLM calls.
